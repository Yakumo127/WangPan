# 暂时搁置修复事项

> 用于记录已识别但暂未立即实施的修复/加固事项，仅作总览索引，具体方案请参见对应设计或实施文档。

- 下载直链安全强化（生产环境）：
  1. 换掉示例 `download.token.secret`，在真实部署中使用高熵随机 secret（建议 32 字节以上），通过环境变量或安全配置注入，而非在仓库中硬编码。
  2. 保持 HTTPS 全站启用，避免下载 token 被中间人被动监听；同时在应用日志与反向代理日志中避免裸打 token，并合理设置 Referer 策略。
  > 详细背景与完整方案见《[下载直链与一次性Token设计方案_20251120-1144](specs/下载直链与一次性Token设计方案_20251120-1144.md)》第 3.7 节“生产环境配置与运维建议”。

- Office 文档预览增强（doc/ppt → PDF 转换）：
  1. 评估并接入后端文档转换能力（例如 LibreOffice headless/JODConverter 或第三方文档预览服务），实现 doc/docx/ppt/pptx → pdf 的稳定转换。
  2. 设计转换结果缓存与失效机制（首次预览转换，后续命中缓存；源文件更新后自动失效旧 PDF），并在预览接口中优先返回 PDF 以获得统一预览体验。
  > 当前版本仅对 doc/ppt 提供“尝试预览”（取决于浏览器支持），完整的转换预览方案见《[文件预览功能设计方案_20251120-1324](specs/文件预览功能设计方案_20251120-1324.md)》第 5 章“doc/ppt → PDF 转换预览方案（搁置项）”的说明。

- 系统设置页备份作业自动刷新与超时提示优化：
  1. 调整 `System.vue` 中“备份作业与进度”列表自动刷新策略，仅在停留在“备份与迁移”页签且用户明确开启自动刷新时轮询 `/api/admin/settings/backup/jobs`，离开页签或关闭开关时停止轮询，避免无意义的定期请求与 Axios 超时刷屏。
  2. 在全局 Axios 响应拦截器中区分 `ECONNABORTED`（请求超时）与纯网络错误，将“网络错误，请检查您的网络连接”优化为更准确的“请求超时，请稍后重试”提示，减少误导。
