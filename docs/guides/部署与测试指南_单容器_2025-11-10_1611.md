# 企业级文件管理系统 — 单容器部署与测试指南（2025-11-10 16:11）

（本指南覆盖：项目结构要点、单容器构建与运行、健康检查、初始化、API 测试清单、前端端到端与常见问题）

## 1. 项目结构要点
- 后端核心：
  - 启动：backend/src/main/java/com/filemanager/FileManagerApplication.java
  - 安全：backend/src/main/java/com/filemanager/config/SecurityConfig.java（下载需登录；管理员端点需 ROLE_ADMIN）
  - 认证：backend/src/main/java/com/filemanager/controller/AuthController.java（登录/注册/用户信息/资料/改密/验证码）
  - 文件：backend/src/main/java/com/filemanager/controller/FileController.java（上传/列表/下载/软删/重命名/移动/复制/搜索/回收站/缩略图）
  - 文件服务：backend/src/main/java/com/filemanager/service/FileService.java（配额：上传/复制扣减；永久删除/清空释放；缩略图生成）
  - 文件夹：backend/src/main/java/com/filemanager/controller/FolderController.java + service/FolderService.java（路径为简化）
  - 管理员：backend/src/main/java/com/filemanager/controller/AdminController.java（用户 CRUD/搜索/导入/导出/下载模板）
  - 用户服务：backend/src/main/java/com/filemanager/service/UserService.java（导入/导出/模板；登录失败锁定）
  - 验证码：backend/src/main/java/com/filemanager/service/CaptchaService.java（小写键存取）
  - 配置：backend/src/main/resources/application.yml（spring.redis 与 spring.cache 顶层；file.storage.path）
- 前端核心：
  - 路由：frontend/src/router/index.js（requiresAuth/requiresAdmin）
  - 状态：frontend/src/store/auth.js（ROLE_ADMIN 判断）
  - 请求：frontend/src/utils/request.js（token 注入；blob 透传）
  - 页面：Login.vue / files/List.vue / folders/List.vue / Recycle.vue / admin/Users.vue / Profile.vue / Share.vue（占位）
- 部署：
  - 单容器 Dockerfile：config/Dockerfile（JDK/Node/MySQL/Redis/Nginx/Supervisor）
  - Compose（参考）：docker-compose.yml

## 2. 构建镜像（单容器）
```bash
cd /work/work_dir/20251110/WangPan
docker build -f config/Dockerfile -t enterprise-file-manager:latest .
```

## 3. 启动容器（持久化与端口映射）
```bash
docker run -d --name file-manager --restart unless-stopped \
  -p 80:80 -p 8080:8080 -p 3306:3306 -p 6379:6379 \
  -v $(pwd)/data/mysql:/var/lib/mysql \
  -v $(pwd)/data/redis:/var/lib/redis \
  -v $(pwd)/storage:/app/storage \
  -v $(pwd)/logs:/app/logs \
  enterprise-file-manager:latest
```

## 6. API 测试清单（curl）
```bash
# 登录（管理员）
TOKEN=$(curl -sS -X POST http://localhost:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}' | sed -E 's/.*"token"\s*:\s*"([^"]+)".*/\1/')

# 用户信息
curl -sS http://localhost:8080/api/auth/userinfo -H "Authorization: Bearer $TOKEN"

# 上传
curl -sS -X POST http://localhost:8080/api/files/upload \
  -H "Authorization: Bearer $TOKEN" -F file=@/path/to/file.txt

# 列表
curl -sS http://localhost:8080/api/files/list -H "Authorization: Bearer $TOKEN"

# 下载（需登录）
curl -fL http://localhost:8080/api/files/download/1 \
  -H "Authorization: Bearer $TOKEN" -o downloaded.bin

# 回收站（用户）：软删→列表→恢复→彻删→清空
curl -sS -X DELETE http://localhost:8080/api/files/1 -H "Authorization: Bearer $TOKEN"
curl -sS http://localhost:8080/api/files/recycle/bin -H "Authorization: Bearer $TOKEN"
curl -sS -X PUT http://localhost:8080/api/files/1/restore -H "Authorization: Bearer $TOKEN"
curl -sS -X DELETE http://localhost:8080/api/files/recycle/bin/1 -H "Authorization: Bearer $TOKEN"
curl -sS -X DELETE http://localhost:8080/api/files/recycle/bin/empty -H "Authorization: Bearer $TOKEN"

# 缩略图（公开）
curl -fL http://localhost:8080/api/files/thumbnail/1 -o thumb.jpg

# 管理员：用户列表/导出/模板/导入
curl -sS http://localhost:8080/api/admin/users -H "Authorization: Bearer $TOKEN"
curl -fL http://localhost:8080/api/admin/users/export -H "Authorization: Bearer $TOKEN" -o users.xlsx
curl -fL http://localhost:8080/api/admin/users/import/template -H "Authorization: Bearer $TOKEN" -o users_import_template.xlsx
curl -sS -X POST http://localhost:8080/api/admin/users/import \
  -H "Authorization: Bearer $TOKEN" -F file=@users_import_template.xlsx
```
