# 前端上传与策略管理对接指南（2025-11-17）

## 用户侧上传（frontend/src/views/files/List.vue）
- 直传：小文件（<=10MB）使用 ，带进度回调。
- 哈希与秒传：计算 SHA-256（SubtleCrypto），调用 ，同用户有同哈希即秒传成功。
- 分片上传：大文件（>10MB）按 10MB 分片；并发 3、每片重试 3 次；失败指数退避 500ms*n。
- 断点续传：
  - 本地： 记录已完成分片编号。
  - 服务端： 返回 ；合并前优先补传 。
- 合并：；合并前提示，失败提供“72小时内可续传”的引导。
- 本地限额：默认 100MB，超限前置拦截避免 413。

## 管理端策略（frontend/src/views/admin/System.vue）
- allowAll 开关 + 白名单编辑（仅小写字母数字，不含点）。
- 常用后缀/分类一键添加：图片、文档、压缩、音频、视频。
- 策略导出：下载 JSON（allowAll、allowedSuffixes、导出时间）。
- 策略导入：文件/粘贴 JSON → 预览 → 与当前差异对比（含详情）→ 覆盖保存。
- 模板化策略：
  - 模板选择：动态来源于模板集合（localStorage 持久化），提供变更预览。
  - 模板配置：JSON 编辑、校验报告（非法后缀/空白白名单）、导出、恢复默认、保存。

## 错误提示策略
- 413：统一提示“文件过大，超出限制”（响应拦截器处理）。
- 400：显示后端返回 。
- 合并失败：提示“已上传分片 72 小时内保留，可稍后重试”。

## 可配置点（建议透出为配置）
- 分片阈值：10MB
- 并发度：3
- 单片重试：3
- 本地前置大小校验：100MB
- 分片保留期：72h（后端配置 ）

## 注意事项
- 前端 SubtleCrypto 哈希会读取完整文件到内存，建议 <=100MB；如需更大文件，替换为增量哈希库。
- 白名单策略（allowAll=false）下，前端应在选择/导入策略时确保后缀合法，后端已二次过滤兜底。
