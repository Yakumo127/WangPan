## 待办与建议
- 分享模块：后端缺失，前端 Share.vue 为模拟数据。
- 存储配额：上传未校验/扣减；建议在 FileService.upload 中校验 `hasEnoughQuota` 与 `useQuota`，删除/恢复联动 `quotaUsed`。
- 操作日志：仅实体存在；建议 AOP 记录登录、上传、下载、删改、移动、复制、恢复、彻删、改密/改资料等。
- 路径接口：FolderService.getFolderPath 仅返回当前节点，可扩展为向上追溯路径链。
- 下载鉴权与放行不一致：
  - Security 放行 `/api/files/download/**`（backend/src/main/java/com/filemanager/config/SecurityConfig.java:47），但控制器依赖 `Authentication`（FileController.java:75-79）。未登录将失败。
  - 方案：去掉放行或调整控制器支持公开访问场景（并做授权校验）。
- 健康检查路径：`config/backend/Dockerfile` 使用 `/api/actuator/health`，`docker-compose.yml` 为 `/actuator/health`。建议统一为 `/actuator/health`。
