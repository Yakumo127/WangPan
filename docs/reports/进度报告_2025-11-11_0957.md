# 企业级文件管理系统 — 项目进度报告（2025-11-11 09:57）

**项目概览**
- 架构与栈：Spring Boot 3 + JPA + Security + JWT + MySQL + Redis；Vue 3 + Element Plus + Axios；Docker/Compose 与 Nginx 支持
- 核心域：用户/认证、文件/文件夹、回收站（用户/管理员）、管理员用户管理、缩略图、配额
- 运行方式：本地（Maven/Vue CLI）、Compose 多容器、单容器镜像（参考 `config/` 与 `docker-compose.yml`）
- 说明范围：自研源码与配置作细致分析；第三方与构建产物（`node_modules/`、`backend/target/`、`frontend/dist/`）略过

**目录结构**
- 后端：`backend/src/main/java/com/filemanager`（`controller/`、`service/`、`repository/`、`entity/`、`security/`、`config/`）与 `resources/`
- 前端：`frontend/src`（`api/`、`views/`、`layout/`、`router/`、`store/`、`utils/`）
- 配置与部署：`config/`（后端/前端 Dockerfile、Nginx、Redis/MySQL 配置、单容器说明）+ `docker-compose.yml`
- 数据库与脚本：`database/`、`scripts/`

**后端关键点**
- 安全

  - `backend/src/main/java/com/filemanager/security/JwtAuthenticationFilter.java`：解析 Bearer Token，注入认证上下文
  - `backend/src/main/java/com/filemanager/security/JwtUtils.java`：HS256 签发与校验（`jwt.secret`、`jwt.expiration`）
- 初始化
  - `backend/src/main/java/com/filemanager/config/DataInitializer.java`：创建管理员 `admin/admin123` 与 `demo/demo123`（必要时重置）
- 认证与用户
  - `backend/src/main/java/com/filemanager/controller/AuthController.java`：注册/登录/管理员登录/用户信息/资料/改密/验证码图片
  - `backend/src/main/java/com/filemanager/service/UserService.java`：登录失败锁定、管理员登录、用户 CRUD、搜索；Excel 导入/导出/模板（Apache POI）
  - `backend/src/main/java/com/filemanager/entity/User.java`：配额字段与增减；`Role { USER, ADMIN }`
- 文件与文件夹
  - `backend/src/main/java/com/filemanager/controller/FileController.java`：上传/列表/下载/重命名/移动/复制/搜索；用户与管理员回收站（列表/恢复/彻删/清空）；公开缩略图
  - `backend/src/main/java/com/filemanager/service/FileService.java`：上传/复制校验并扣配额；永久删除/清空释放配额；下载计数；管理员文件分页与关键字检索；生成并缓存缩略图
  - `backend/src/main/java/com/filemanager/repository/FileRepository.java`：多维度查询与分页
  - `backend/src/main/java/com/filemanager/controller/FolderController.java` + `service/FolderService.java`：文件夹 CRUD/移动/路径（简化为当前节点）
- 管理员
  - `backend/src/main/java/com/filemanager/controller/AdminController.java`：用户列表/搜索/新增/更新/删除；导入/导出/下载模板（已实现）

**重要问题与风险**
- 角色值不一致（管理员用户管理）
  - 列表显示与表单提交使用的 `ROLE_ADMIN/ADMIN` 存在不一致，可能导致标签显示错误或 400 反序列化失败
  - 建议统一前端使用 `ADMIN/USER` 与后端实体一致；管理员权限判断继续基于 `ROLE_ADMIN`
- 验证码未参与登录校验：DTO 含 `captcha`，`UserService.login` 未校验（可后续增强）
- 缩略图生成的内存使用：大图 `ImageIO.read` 可能吃内存，建议加尺寸/格式与异常保护
- 软删与配额：软删不释放配额、永久删除/清空释放配额（当前符合预期）
- 仓库冗余：`*.backup/.bak` 与构建产物存在，可后续清理
