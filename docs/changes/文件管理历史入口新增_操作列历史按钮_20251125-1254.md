# 文件管理“历史”入口新增需求说明（操作列历史按钮）

## 问题与目标
- 现状：新版文件管理（Explorer）操作列的下拉菜单仅包含预览、移动、复制，缺少直接查看历史版本的入口。
- 目标：在文件行的下拉“小三角”菜单中新增“历史”项，点击即可查看该文件的版本列表，方便用户快速定位历史版本。

## 方案摘要
- 在前端 `Explorer.vue` 的文件操作下拉菜单中增加“历史”按钮。
- 新增接口封装 `getFileVersions(fileId)` 调用后端 `/files/{fileId}/versions`。
- 打开“历史”弹窗，展示版本号、大小、类型、创建人/时间、备注等基本信息。

## 实施要点
- 仅改动新版文件管理页面（旧版已隐藏，不改动）。
- 使用现有尺寸/时间格式化函数，避免重复逻辑。
- 保持中文文案，与现有 UI 风格一致。

## 影响范围
- 前端：`frontend/src/views/files/Explorer.vue`、`frontend/src/api/file.js`
- 交互：新增弹窗与下拉菜单项，不影响现有上传/下载/移动/复制逻辑。

## 风险与缓解
- 风险：版本接口异常时弹窗空白或报错。
- 缓解：加载态和错误提示；失败时仍可关闭弹窗不影响其他功能。
