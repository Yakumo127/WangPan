# 文件预览：新版预览页布局微调（2025-11-20 18:22）

## 一、问题与目标

在 `/file-view/:id` 新预览页初版基础上，用户提出了两点布局问题：

1. 文件信息“详情”列的位置不符合预期：
   - 当前实现中，文件信息栏位于预览区域左侧；
   - 用户期望文件信息栏在右侧，预览内容在左侧。

2. 顶部四个操作按钮（下载、历史、详情、返回文件列表）之间间距偏大：
   - 目前每个按钮之间存在较大的水平间距；
   - 希望四个按钮更紧凑地集中在一起，视觉上更像一组操作，而不是分散的单个按钮。

本次微调的目标：

- 将文件信息栏移动到预览区域右侧；
- 将四个操作按钮收紧为一组，减少它们之间的视觉间隙。

## 二、布局调整设计

### 1. 文件信息栏移动到右侧

当前主体布局结构（简化）：

```vue
<div class="file-preview-layout">
  <aside v-if="showSidebar" class="file-preview-sidebar">...</aside>
  <main class="file-preview-content">...</main>
</div>
```

将其调整为：

```vue
<div class="file-preview-layout">
  <main class="file-preview-content">
    <!-- 预览内容（视频 / 文本 / iframe） -->
  </main>
  <aside v-if="showSidebar" class="file-preview-sidebar">
    <!-- 文件信息 -->
  </aside>
</div>
```

对应样式调整：

- 原先 `.file-preview-sidebar` 使用 `border-right` 将信息栏与预览区分隔；
- 改为使用 `border-left`：

```css
.file-preview-sidebar {
  width: 260px;
  border-left: 1px solid #ebeef5;
  padding: 16px;
  box-sizing: border-box;
  background: #fafafa;
}
```

这样结构为：左侧预览内容、右侧信息栏，符合用户期望。

### 2. 顶部按钮组收紧布局

当前顶部按钮结构：

```vue
<div class="header-actions">
  <el-button size="small" @click="goBack">返回文件列表</el-button>
  <el-button size="small" @click="toggleDetails">详情</el-button>
  <el-button size="small" @click="handleHistory">历史</el-button>
  <el-button size="small" @click="handleDownload">下载</el-button>
</div>
```

为使四个按钮看起来更像一组，调整为使用 `el-button-group` 包裹：

```vue
<div class="header-actions">
  <el-button-group>
    <el-button size="small" @click="goBack">
      <el-icon><ArrowLeft /></el-icon> 返回文件列表
    </el-button>
    <el-button size="small" @click="toggleDetails">详情</el-button>
    <el-button size="small" @click="handleHistory">历史</el-button>
    <el-button size="small" @click="handleDownload">
      <el-icon><Download /></el-icon> 下载
    </el-button>
  </el-button-group>
</div>
```

`header-actions` 样式保持简洁：

```css
.header-actions {
  display: flex;
  align-items: center;
}
```

通过 `el-button-group`，按钮之间的间距将由 Element Plus 控制，四个按钮贴得更近，视觉上更统一。

## 三、实现要点

文件：`frontend/src/views/files/PreviewNew.vue`

1. 模板修改

- 调整主体布局中 `<main>` 与 `<aside>` 的顺序；
- 将顶部按钮区域改为使用 `el-button-group`：

```vue
<div class="header-actions">
  <el-button-group>
    <!-- 返回 / 详情 / 历史 / 下载 -->
  </el-button-group>
</div>
```

2. 样式修改

- `.file-preview-sidebar` 改为 `border-left`，移除 `border-right`；
- `.header-actions` 仅负责垂直居中，不再设置额外 gap，由 `el-button-group` 接管按钮间距。

## 四、影响评估

1. 功能行为
- 不涉及任何逻辑、状态或 API 调用的变更，仅调整布局与样式；
- 文件信息栏的显示开关仍由“详情”按钮控制，逻辑不变；
- “下载”“历史”“返回文件列表”按钮行为不变。

2. 视觉与体验
- 预览内容在左、文件信息在右，更符合常见文件管理 UI 习惯；
- 四个按钮收拢成一组，操作区域更加紧凑、清晰。

3. 风险
- 改动范围局限在新版预览页，不影响旧预览页或其他页面；
- 若视觉效果仍不满足期望，可继续在此基础上微调间距或按钮顺序。
