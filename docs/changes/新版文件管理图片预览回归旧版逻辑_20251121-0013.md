# 新版文件管理图片预览回归旧版逻辑（2025-11-21 00:13）

## 需求
- 将新版文件管理（Explorer）中的图片预览体验改为旧版文件列表的逻辑：点击图片直接弹出图片预览对话框（支持缩放、关闭时释放 URL），而非跳转到新版预览页。

## 实施
- `frontend/src/views/files/Explorer.vue`：
  - 引入 `previewFile` 接口，点击/双击图片时直接请求预览 Blob，生成本地 URL 并弹出对话框。
  - 保留其他类型走新版预览路由。
  - 复用旧版的滚轮缩放、关闭释放 URL 的行为。
  - 增加图片预览对话框样式与交互。

## 影响范围
- 仅前端图片预览逻辑与相关样式，其他文件类型和上传/下载不受影响。

## 验证
- 在新版文件管理中点击图片：应直接弹出图片预览对话框，可滚轮缩放，关闭后释放 URL；非图片仍跳转新版预览页。无需刷新跳转。
