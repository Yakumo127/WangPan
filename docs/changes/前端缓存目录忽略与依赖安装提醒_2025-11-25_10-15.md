# 前端缓存目录忽略与依赖安装提醒（2025-11-25 10:15）

## 问题成因
- 早期前端构建缓存目录 `frontend/node_modules/.cache/babel-loader` 被纳入版本控制，文件量巨大，影响仓库体积与操作效率。
- 更新前端并清理缓存后，为防止后续再次提交缓存，需要在 `.gitignore` 中显式忽略该目录。
- 执行 `npm ci` 时出现多条依赖废弃/不再维护的警告（如 `npmlog@5.0.1`、`gauge@3.0.2`、`webpack-chain@6.5.1`、`eslint@8.57.1` 等），需提示后续依赖升级规划。

## 排查过程与历史
- 用户已用新前端覆盖并删除 `frontend/node_modules/.cache`，导致 Git 中成千上万的缓存文件被标记删除。
- 检查仓库 `.gitignore`，发现仅忽略了 `frontend/node_modules/` 与 `frontend/dist/`，未覆盖 `.cache` 目录。
- 本次在用户授权下，计划通过添加忽略规则避免缓存再次入库，并记录现有 `npm ci` 的依赖废弃警告。

## 修复建议
- 在根目录 `.gitignore` 增加 `frontend/node_modules/.cache/` 忽略规则，防止构建缓存再次被提交。
- 保持每次覆盖或安装依赖后执行 `npm ci`/`npm install`，如遇缓存生成也不会进入版本库。
- 针对 `npm ci` 出现的废弃/不维护依赖，后续安排依赖升级评估（需关注构建链路与 Vue CLI 兼容性）。

## 实际采取的修复操作
- 生成本报告记录缓存忽略需求与 `npm ci` 警告情况。
- 准备在 `.gitignore` 中新增 `frontend/node_modules/.cache/` 忽略规则，并在文档变更总记录登记本次操作。
