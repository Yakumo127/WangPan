# 文件管理新版图片预览弹窗尺寸缩减（2025-11-21 08:36）

## 问题成因
- 新版文件管理（Explorer）中的图片预览对话框沿用了宽度 70% + 内容区 80vh 高度、图片 `min-width: 80vh / min-height: 70vh` 的配置。该组合在常见 1080p 分辨率下会占据接近全屏的视口面积，导致弹窗观感偏大。
- 旧版列表页曾为解决“小图过小”问题而加入较大的最小宽高，但在新版 Explorer 场景中，较大的最小尺寸使整体弹窗显得过于占屏。

## 排查过程与历史
- 查阅 `docs/changes/图片预览最小尺寸与居中优化_20251120-1702.md`、`docs/changes/图片预览最小尺寸单位修正_20251120-1704.md`，确认曾为放大小图设置 `min-width/min-height`。
- 确认新版文件管理相关逻辑在 `docs/changes/新版文件管理图片预览回归旧版逻辑_20251121-0013.md` 中落地，当前样式继续沿用大尺寸配置。
- 现场查看 `frontend/src/views/files/Explorer.vue`，对话框宽度为 70%，容器高度 80vh，图片最小尺寸 80vh/70vh，导致默认弹窗面积过大。

## 修复建议
- 适度缩小对话框宽度与内容区高度，使整体弹窗缩小约 15%-20%，保持居中与滚轮缩放交互不变。
- 同步下调图片最小宽高，兼顾小图放大需求与避免过度占屏。

## 实际采取的修复操作
- `frontend/src/views/files/Explorer.vue`：
  - 将图片预览对话框宽度由 70% 下调至 60%，降低默认横向占屏。
  - 将预览容器高度由 80vh 调整为 70vh，使对话框整体高度收缩。
  - 将图片最大高度由 80vh 调整为 70vh，并将最小宽高从 80vh/70vh 下调为 60vh/55vh，保持按比例缩小但仍提供基本放大效果。

## 验证要点
- 在新版文件管理中选择图片预览：弹窗宽高相较之前明显减小，仍保持居中展示。
- 滚轮缩放仍可用，关闭后图片 URL 需被释放（与既有逻辑一致）。
- 大尺寸图片应在 70vh 内等比例缩放，小尺寸图片在 60vh/55vh 下仍易于查看且不再占据过多屏幕。
