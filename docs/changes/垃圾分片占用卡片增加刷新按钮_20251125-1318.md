# 垃圾分片占用卡片增加刷新按钮

## 背景与问题
- 系统设置「存储与空间」页的“垃圾分片占用”卡片仅有“清理所有”操作，缺少手动刷新入口。
- 用户需要在不清理的情况下查看最新分片占用统计。

## 方案
- 在“垃圾分片占用”卡片的操作区域新增“刷新”按钮，调用现有 `loadStorageSummary` 方法重新获取数据。
- 按钮添加 `@mousedown.prevent` 防止连续点击选中文本，loading 状态复用 `storageLoading`。

## 影响范围
- 前端 `frontend/src/views/admin/System.vue`
- 文档记录（本文件、总记录更新）

## 预期结果
- 用户可在卡片上直接刷新占用数据，不会影响清理按钮行为或触发文本选中。
