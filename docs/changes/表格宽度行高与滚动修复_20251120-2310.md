# 表格宽度行高与滚动修复（2025-11-20 23:10）

## 问题
- Element Plus 表格默认 `fit=true` 自动拉伸列宽，导致自定义宽度不生效。
- 行高仅设置行容器高度，未同步单元格内边距，视觉高度未压缩。
- 列表容器 `overflow: hidden` 导致内容超出时行被裁切且无法滚动。

## 修复
- `frontend/src/views/files/Explorer.vue`：
  - 在表格上设置 `:fit="false"` 并启用 `table-layout: fixed`，按设定列宽展示。
  - 容器 `overflow` 改为 `hidden auto`，并强制 `.el-table__body-wrapper` 支持纵向滚动。
  - 为单元格增加紧凑的 padding 与行高，使整体行高与视觉高度一致。

## 风险与验证
- 纯样式与表格布局属性调整，不涉及业务逻辑。需在浏览器确认：列宽按设定显示、40px 行高生效，内容超出时可滚动且不被隐藏。
