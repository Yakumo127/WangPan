# 表头固定与选择列实现（2025-11-20 23:52）

## 问题
- 表头随内容滚动，影响查看列标题。
- 需求新增“表头全选 + 行选择框”列。
- 列宽固定需求与表格宽度、滚动需兼顾。

## 处理
- `frontend/src/views/files/Explorer.vue`：
  - 表格开启 `height="100%"`，配合容器固定高度，让表头固定，滚动仅作用于表体。
  - 添加选择列，表头复选框可全选/全不选；行选择变化时更新全选/半选状态，切换目录时自动清空选中。
  - 保持表格宽度 100% 且 `table-layout: fixed`，列宽按设定值展示（名称 345、大小 100、类型 120、创建时间 160、操作 180）。
  - 容器 `overflow` 改为 hidden，滚动交由表体处理；单元格 padding/行高保持紧凑。

## 风险与验证
- 仅涉及前端表格交互与样式，无业务逻辑改动。需在浏览器确认：表头固定不随滚动，表头全选/全不选正常，切换目录时选中状态清空。
