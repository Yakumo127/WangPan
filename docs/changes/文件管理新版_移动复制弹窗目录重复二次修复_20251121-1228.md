# 文件管理新版移动/复制弹窗目录重复二次修复（2025-11-21 12:28）

## 问题复现
- 首次打开“移动/复制”弹窗时，文件夹树出现重复节点（如 aa, bb, aa, bb）；关闭弹窗后再次打开恢复正常。

## 原因分析
- 后端已改为返回瘦身 DTO，但前端树形数据在首次加载时会多次累积同一批节点：
  - 打开弹窗时初始化根节点数据，并在树组件懒加载回调中再次追加，缺少去重保护。
  - 当 `default-expanded-keys` 展开根节点时，会触发 `load` 回调，返回的根节点与初始数据重复，直接 `resolve` 追加导致重复展示。

## 修复思路
- 在前端对树节点加载过程增加去重保护，统一通过 Map 按 id 去重后再赋值。
- 根节点加载时清空旧数据，确保初次渲染不会叠加旧列表。

## 实际改动
- `frontend/src/views/files/Explorer.vue`：
  - `loadFolderTreeRoot` 先清空树数据与展开列表，再将返回的根节点通过去重函数写入。
  - `loadFolderChildren` 结果去重后返回，避免重复追加。
  - 新增工具函数 `dedupeFolders(arr)` 按 id 去重，所有树数据加载环节统一使用。

## 影响评估
- 仅调整前端树数据的组装逻辑，接口与后端行为不变。
- 首次打开弹窗避免重复节点，后续打开也不会叠加旧数据，风险低。***
