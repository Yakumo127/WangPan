## 修复方案
- 仅在 `image-preview-dialog` 作用域内覆写 `.el-dialog__header`/`.el-dialog__title`，使标题在水平居中；不改动其他对话框。

  - 可选对标题本身设定 `text-align: center`，确保在 flex 布局下保持居中。
