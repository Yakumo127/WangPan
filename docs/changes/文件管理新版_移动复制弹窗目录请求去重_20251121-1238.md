# 文件管理新版移动/复制弹窗目录请求去重（2025-11-21 12:38）

## 问题现象
- 首次打开移动/复制弹窗会向 `/api/folders/list` 发起多次重复请求（根目录与多个 parentId 反复请求），导致目录节点重复渲染。
- 关闭弹窗再打开恢复正常，但首轮体验混乱。

## 原因分析
- 弹窗打开时先拉取根节点并设置 `default-expanded-keys` 展开根列表；Element-Plus Tree 在默认展开时会触发懒加载回调，多次向相同 `parentId` 发送请求。
- 前端未对目录请求做缓存/去重，导致同一 `parentId` 被重复请求并叠加渲染。

## 修复方案
- 对目录请求增加缓存与去重：
  - 引入 `folderCache`（Map），按 `parentId` 缓存已加载结果；已缓存则直接返回，不再请求。
  - 根节点加载前清空缓存与树数据，避免叠加旧状态。
  - 去掉默认展开（`expandedKeys` 为空），让用户点击节点时再触发加载。

## 实际改动
- `frontend/src/views/files/Explorer.vue`：
  - 新增 `folderCache`，在根、子节点加载时优先返回缓存。
  - 打开弹窗时清空缓存/树数据；根加载仅请求一次并缓存。
  - 取消默认展开，避免 Tree 自动触发多次懒加载。

## 影响评估
- 请求次数显著减少，同一 `parentId` 仅请求一次；目录树首次打开不再重复节点。
- 仅前端逻辑调整，风险低。***
