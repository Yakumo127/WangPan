# 图片预览滚轮缩放方案（2025-11-20 17:15）

## 一、问题与目标

1. 现状
- 图片预览对话框已完成两轮优化：
  - 对话框宽度调整为 `70%`，去掉 body padding；
  - 图片样式：
    - `max-width: 100%`；
    - `max-height: 80vh`；
    - `min-width: 80vh`（放大小图）；
    - 居中显示，`object-fit: contain`；
- 对大部分图片，预览效果已经较为自然；
- 但目前预览只是“静态缩放”，用户无法在预览框内进一步放大 / 缩小查看细节。

2. 目标
- 在不修改后端逻辑的前提下，为图片预览增加“滚轮缩放”能力：
  - 鼠标滚轮向上：放大图片；
  - 鼠标滚轮向下：缩小图片；
  - 保持图片宽高比不变；
  - 图片始终在预览框内居中展示；
  - 每次打开预览时缩放比例重置为 1。

## 二、技术思路

1. 不改请求逻辑，增加前端缩放状态
- 继续使用现有的 `previewImage(file)` 逻辑：
  - 通过 `/api/files/{id}/preview` 获取 Blob；
  - 使用 `URL.createObjectURL(blob)` 生成 `imagePreviewUrl`；
  - 打开图片预览对话框。
- 新增一个响应式缩放状态：
  ```js
  const imageScale = ref(1)
  ```
- 每次打开预览时将 `imageScale` 重置为 1，保证用户从“原始缩放”开始查看。

2. 使用 CSS transform 实现放大 / 缩小
- 在模板中，为图片增加基于 `imageScale` 的缩放样式：
  ```vue
  <img
    v-if="imagePreviewUrl"
    :src="imagePreviewUrl"
    class="image-preview-img"
    :style="{ transform: `scale(${imageScale})` }"
  />
  ```
- 保持原有 `max-width` / `max-height` / `min-width` 约束，用 CSS 控制图片在预览区域内的最大/最小表现；
- `transform: scale(...)` 在这些约束基础上进一步放大/缩小，但不改变图片本身的宽高比。

3. 通过包裹容器监听滚轮事件
- 在图片外增加一层包裹容器，用于：
  - 监听鼠标滚轮事件；
  - 处理居中和滚动条；
  ```vue
  <div class="image-preview-wrapper" @wheel.prevent="onImageWheel">
    <img ... />
  </div>
  ```
- 滚轮事件处理逻辑：
  ```js
  const onImageWheel = (event) => {
    const delta = event.deltaY || 0
    let next = imageScale.value
    if (delta > 0) {
      // 向下滚轮：缩小
      next -= 0.1
    } else if (delta < 0) {
      // 向上滚轮：放大
      next += 0.1
    }
    // 限制缩放范围，例如 0.5 ~ 4
    if (next < 0.5) next = 0.5
    if (next > 4) next = 4
    imageScale.value = next
  }
  ```
- 使用 `@wheel.prevent` 防止页面整体滚动干扰预览体验。

4. 居中与滚动体验
- 为包裹容器增加样式：
  ```css
  .image-preview-wrapper {
    display: flex;
    align-items: center;
    justify-content: center;
    height: 80vh;
    overflow: auto;
  }
  ```
- 效果：
  - 图片在容器内始终居中；
  - 缩放后若图片大于容器，会出现滚动条，允许用户拖动查看；
  - 不改变对话框整体布局。

5. 重置缩放
- 在关闭对话框时，将缩放比例重置为 1，并清空图片 URL（可选）：
  ```js
  const onImagePreviewClosed = () => {
    imageScale.value = 1
    imagePreviewUrl.value = ''
  }
  ```
- 使用 `@closed="onImagePreviewClosed"` 监听对话框关闭事件。

## 三、具体改动方案（前端）

目标文件：`frontend/src/views/files/List.vue`

1. 模板调整

原有图片预览对话框：

```vue
<el-dialog
  v-model="imagePreviewVisible"
  title="图片预览"
  width="70%"
  class="image-preview-dialog"
>
  <img
    v-if="imagePreviewUrl"
    :src="imagePreviewUrl"
    class="image-preview-img"
  />
</el-dialog>
```

调整为：

```vue
<el-dialog
  v-model="imagePreviewVisible"
  title="图片预览"
  width="70%"
  class="image-preview-dialog"
  @closed="onImagePreviewClosed"
>
  <div class="image-preview-wrapper" @wheel.prevent="onImageWheel">
    <img
      v-if="imagePreviewUrl"
      :src="imagePreviewUrl"
      class="image-preview-img"
      :style="{ transform: `scale(${imageScale})` }"
    />
  </div>
</el-dialog>
```

2. 脚本逻辑调整

在 `<script setup>` 中新增：

```js
const imageScale = ref(1)

const openImagePreview = (url) => {
  imagePreviewUrl.value = url
  imageScale.value = 1
  imagePreviewVisible.value = true
}

const onImageWheel = (event) => {
  const delta = event.deltaY || 0
  let next = imageScale.value
  if (delta > 0) {
    next -= 0.1
  } else if (delta < 0) {
    next += 0.1
  }
  if (next < 0.5) next = 0.5
  if (next > 4) next = 4
  imageScale.value = next
}

const onImagePreviewClosed = () => {
  imageScale.value = 1
  imagePreviewUrl.value = ''
}
```

同时将 `previewImage(file)` 中直接设置对话框的逻辑调整为调用 `openImagePreview`：

原先：

```js
const previewImage = async (file) => {
  const resp = await previewFileApi(file.id)
  const blob = resp?.data
  const url = window.URL.createObjectURL(blob)
  imagePreviewUrl.value = url
  imagePreviewVisible.value = true
}
```

修改为：

```js
const previewImage = async (file) => {
  const resp = await previewFileApi(file.id)
  const blob = resp?.data
  const url = window.URL.createObjectURL(blob)
  openImagePreview(url)
}
```

3. 样式调整

在 `<style scoped>` 中新增包裹容器样式，并保留图片原有约束：

```css
.image-preview-dialog :deep(.el-dialog__body) {
  padding: 0;
}

.image-preview-wrapper {
  display: flex;
  align-items: center;
  justify-content: center;
  height: 80vh;
  overflow: auto;
}

.image-preview-img {
  max-width: 100%;
  max-height: 80vh;
  min-width: 80vh;
  display: block;
  margin: 0 auto;
  object-fit: contain;
}
```

> 注：根据用户要求，保留对最小宽度的约束（`min-width: 80vh`），去掉最小高度约束，仅通过 `max-height: 80vh` 控制最大高度。

## 四、影响评估

1. 功能行为
- 图片预览的基础行为（点击文件名 → 弹出对话框 → 显示图片）保持不变；
- 新增功能：
  - 滚轮向上：图片放大；
  - 滚轮向下：图片缩小；
  - 缩放范围为 `0.5x ~ 4x`，避免缩得过小或放得过大；
  - 关闭对话框后，下一次预览回到 `1x` 原始缩放。

2. 视觉与交互体验
- 小图在预览框中既有默认的放大（通过 `min-width`），又可以通过滚轮进一步放大查看细节；
- 大图仍通过 `max-width` / `max-height` 控制整体占比；
- 图片居中 + 可滚动的容器让缩放体验更加自然。

3. 风险与兼容性
- 改动仅限图片预览对话框，不影响其他组件；
- 不修改后端 API 或数据结构；
- 仅使用标准 DOM 事件与 CSS 属性，主流浏览器兼容性良好。

## 五、小结

本次方案在现有“图片预览对话框尺寸优化”的基础上，增加了滚轮缩放能力，满足了“在不破坏比例的前提下放大小图和查看细节”的需求，且完全通过前端实现，不需要调整后端接口。未来如需增强键盘缩放、双击缩放等交互，也可以在当前基础上平滑扩展。
