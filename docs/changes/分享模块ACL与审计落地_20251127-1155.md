# 分享模块 ACL 与审计落地（2025-11-27 11:55）

## 1. 问题成因
- 分享模块缺少 ACL 维护 UI、后端校验与审计打点，公开/受控模式缺乏高风险权限兜底。

## 2. 修复建议
- 后端：增加 shareMode（PUBLIC/CONTROLLED）、公开模式禁高风险位校验、ACL 校验（EMAIL 格式）、审计打点（创建/更新/撤销/验证/下载）。
- 前端：分享创建/编辑表单支持模式/权限选择；ACL 管理弹窗（USER/EMAIL/组），编辑分享保存；列表显示权限标签。

## 3. 实际采取的修复操作
- 后端：
  - `Share` 增加 `shareMode` 字段；`ShareService` 创建/更新兜底禁用公开模式上传/再分享/删移。
  - `replaceAcl` 校验受邀人类型/邮箱格式；`ShareController` 列表返回 shareMode，ACL 接口使用 replaceAcl。
  - 审计：在创建/更新/撤销/验证/下载处写入 AuditLogService（成功/失败）。
- 前端：
  - `Share.vue`：模式选择（公开/受控）、权限复选、编辑对话框、ACL 管理弹窗（添加/移除 USER/EMAIL/组权限）、列表权限标签与搜索过滤。
  - `api/share.js`：补充 ACL 获取/替换接口。
