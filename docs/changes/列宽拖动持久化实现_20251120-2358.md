# 列宽拖动持久化实现（2025-11-20 23:58）

## 目标
- 名称/大小/类型/创建时间/操作列可拖动调整宽度。
- 宽度配置持久化，刷新或重开页面后沿用上次设置。
- 保持表格宽度 100%，列宽固定不随屏幕比例自动拉伸。

## 实施
- `frontend/src/views/files/Explorer.vue`：
  - 为关键列添加 `column-key`，监听 `@header-dragend`，记录拖动后的新宽度。
  - 默认列宽：名称 345，大小 100，类型 120，创建时间 160，操作 180，存储键 `efm_explorer_column_widths_v1`。
  - 通过 localStorage 持久化列宽，页面加载时自动读取并覆盖默认值。
  - 保持表格 `width: 100%; table-layout: fixed; :fit="false"`，确保列宽按配置生效。

## 风险与验证
- 仅前端交互与样式层改动，无后端影响。建议验证：拖动列宽后刷新页面仍保留新宽度；各列拖动不互相干扰；选择列与表头固定行为未受影响。
