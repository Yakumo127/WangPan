# 文件管理新版 - 选择状态工具栏切换实现（2025-11-21 16:23）

## 问题成因
- “文件管理（新版）”列表的工具栏始终展示“新建文件夹”“上传文件”，未根据是否有勾选项切换至批量操作入口，无法满足“选择后显示移动/复制/删除/下载/更多（含重命名）”的需求。
- 列表本身已经支持行选择并维护 `selectedRows`，但未将选择状态用于工具栏逻辑，导致可用的信息未被利用。

## 排查过程与历史
- 浏览 `frontend/src/views/files/Explorer.vue`，确认表格已开启 `type="selection"` 并在 `onSelectionChange` 中维护 `selectedRows`、`allChecked`、`isIndeterminate`。
- 工具栏模板固定渲染“新建文件夹”“上传文件”，未引用选择状态；现有移动/复制/删除/下载/重命名入口只存在于行内操作，缺少批量操作集中入口。
- 现有移动/复制对话框逻辑基于单个条目（`moveCopyItem`）设计，批量处理尚未适配。

## 修复建议
- 基于 `selectedRows` 增加 `hasSelection` 等计算属性：无选择时显示“上传文件”“新建文件夹”，有选择时切换为“移动”“复制”“删除”“下载”“更多（重命名）”工具组。
- 复用现有移动/复制对话框，扩展为可接受批量条目：批量时默认沿用原名，保留单选时的重命名输入；提交时依次调用文件/文件夹的移动或复制接口，并刷新目录与缓存。
- 批量删除/下载/重命名需要基于当前选择：删除区分文件与文件夹接口，下载仅支持文件并提示过滤，重命名限制在单选情况下启用。

## 实际采取的修复操作
- 在 `Explorer.vue` 中加入 `hasSelection`/`singleSelection` 计算属性，工具栏根据是否存在选择切换：未选择时展示“上传文件”“新建文件夹”，存在选择时展示“移动/复制/删除/下载”以及“更多-重命名”（多选时自动禁用重命名）。
- 扩展移动/复制对话框逻辑，引入 `moveCopyItems`/`moveCopyMode` 支持单选与多选；批量操作默认沿用原名，单选时保留重命名输入框；标题与缓存刷新范围随批量条目动态计算，提交时依次调用文件/文件夹的移动或复制接口。
- 新增批量删除/下载/重命名入口：删除共用一次确认并区分文件与文件夹接口，下载仅对文件生效并提示过滤文件夹，重命名仅在单选时调用对应 API；所有批量操作完成后清空选择并刷新列表。
