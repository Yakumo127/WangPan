# 新版上传弹窗支持拖拽文件/文件夹入队（上传队列抽屉）

## 背景
- 新版文件管理（Explorer）目前通过上传按钮直接触发选择文件，缺少弹窗与拖拽区域；不支持在上传 UI 内直接拖拽文件夹递归入队。
- 需要恢复“弹窗 + 拖拽”体验，并支持文件夹递归收集，依然复用底部上传队列抽屉显示进度。

## 方案
1. 上传按钮改为打开弹窗，弹窗内包含：
   - 可拖拽区域，支持文件/文件夹拖入，递归收集文件后调用 `enqueueFiles`。
   - 保留“选择文件”按钮（含 `webkitdirectory`）以兼容选择文件/文件夹。
   - 简要提示，上传进度继续通过现有底部上传队列抽屉展示。
2. 事件处理：
   - `dragover/drop` 阻止默认行为，递归遍历 `DataTransfer.items`、`webkitGetAsEntry` 获取文件。
   - 过滤空目录和无效条目，支持多文件。
3. 影响范围：仅 `frontend/src/views/files/Explorer.vue`；复用 `useUploadQueue`，不改后台接口。

## 风险与缓解
- 大批量文件夹拖入：入队前可显示加载提示，复用现有队列的并发/分片控制。
- 浏览器兼容：目录读取依赖 `webkitGetAsEntry`，在不支持的环境退化为普通文件拖拽。

## 预期结果
- 点击上传按钮弹出对话框，用户可拖拽文件/文件夹或通过按钮选择，拖入的文件自动进入上传队列并在底部抽屉显示进度。
