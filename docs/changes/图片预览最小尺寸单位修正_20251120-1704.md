# 图片预览最小尺寸单位修正（2025-11-20 17:04）

## 一、背景

在“图片预览最小尺寸与居中优化”中，为了放大小图，初步设置了：

- `min-width: 80vh`
- `min-height: 70ch`

其中：

- `vh` 是相对视口高度的单位；
- `ch` 是相对字体字符宽度/高度的单位。

用户希望这两个约束都基于视口高度进行控制，以保持预览尺寸的逻辑一致性。

## 二、修正内容

1. 样式调整

在 `frontend/src/views/files/List.vue` 中，将图片预览样式由：

```css
.image-preview-img {
  max-width: 100%;
  max-height: 80vh;
  min-width: 80vh;
  min-height: 70ch;
  display: block;
  margin: 0 auto;
  object-fit: contain;
}
```

修改为：

```css
.image-preview-img {
  max-width: 100%;
  max-height: 80vh;
  min-width: 80vh;
  min-height: 70vh;
  display: block;
  margin: 0 auto;
  object-fit: contain;
}
```

2. 效果说明

- 宽度与高度最小值现在均以视口高度（`vh`）为参考：
  - `min-width: 80vh`：期望图片宽度至少约为视口高度的 80%；
  - `min-height: 70vh`：期望图片高度至少约为视口高度的 70%；
- 结合 `max-width: 100%` 与 `max-height: 80vh`：
  - 浏览器将在不改变图片宽高比的前提下，在这几个约束之间寻找平衡；
  - 小图会被尽量放大以填满预览区域，大图仍受最大尺寸限制；
  - 由于使用 `object-fit: contain`，图片不会被拉伸或裁切。

## 三、影响评估

- 仅调整了预览图片的最小高度单位，不涉及任何逻辑代码；
- 视觉上会使小图在竖直方向放得更大一些，更符合“宽高都相对视口”的预期；
- 其他对话框和页面不受影响，风险可控。
