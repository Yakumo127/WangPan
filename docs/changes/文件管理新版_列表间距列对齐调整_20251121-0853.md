# 文件管理新版列表间距与列对齐调整（2025-11-21 08:53）

## 问题成因
- 最新样式中，文件列表单元格内边距为 `6px 8px`，在密集列表模式下左右留白稍大，导致有效信息宽度减少。
- “大小”与“类型”两列的文本为左对齐，与数据的数值类展示习惯不一致（通常倾向居中或右对齐），观感略显不齐。

## 排查过程与历史
- 查看 `frontend/src/views/files/Explorer.vue` 样式：`.entries-list :deep(.el-table__cell) { padding: 6px 8px; line-height: 20px; }`，左右 padding 为 8px。
- 表头与列定义中未对“大小”“类型”列设置 `align`，沿用表格默认左对齐。
- 上次调整集中在弹窗尺寸与标题居中，未触及列表间距与列对齐。

## 修复方案
- 将列表单元格 padding 调整为 `6px 6px`，略微收紧左右间距，提升信息密度。
- 为“大小”和“类型”列设置 `align="center"`，保持数值/类型类信息居中展示。

## 实际采取的修复操作
- `frontend/src/views/files/Explorer.vue`：
  - 将 `.entries-list :deep(.el-table__cell)` padding 从 `6px 8px` 调整为 `6px 6px`，收紧左右间距。
  - 为“大小”与“类型”列增加 `align=\"center\"`，使列内文本居中。
- 更新文档总记录并提交推送。

## 影响评估
- 仅影响新版文件管理列表的单元格内边距与两列对齐方式，不涉及逻辑代码。
- 风险低，可通过界面预览快速验证。
