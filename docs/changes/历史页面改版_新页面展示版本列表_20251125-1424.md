# 历史页面改版（新页面展示版本列表）

## 需求
- 点击“历史”后跳转到新页面，展示版本列表，列：时间（最新标记当前版本）、修改者（带图标+用户名）、大小（格式化），右侧操作为竖向三点菜单包含“下载”“查看（预览）”。

## 方案
- 新增历史页面路由 `/file-history/:id`，加载版本列表。
- 列表数据来源：后端 `/files/{fileId}/versions`，时间列标记最新版本为“当前版本”。
- 修改者显示创建者 ID，当前用户匹配时显示当前用户名，附带头像样式占位。
- 操作菜单：
  - 下载：通过新 API `downloadFileVersion` 拉取指定版本 Blob 并触发浏览器下载。
  - 查看：同样拉取 Blob，针对浏览器可预览类型（image/pdf/text）直接 `window.open` 预览，否则回退下载。
- Explorer 中“历史”按钮改为跳转到新页面。

## 影响范围
- 前端：新增历史页面组件与路由；更新 Explorer 历史入口；新增文件 API。

## 风险与缓解
- 预览能力依赖浏览器对类型支持：限定常见图片/PDF/text，其他类型回退下载。
- 版本创建者仅有 `createdBy` ID，暂用当前用户匹配，其他用户显示“用户#ID”占位，后续可扩展用户查询接口。
