# 分享弹窗样式优化（2025-11-28 09:26）

## 问题成因
- 分享弹窗（ACL 对话框）布局简单，仅表格+表单，缺少清晰的左右分栏与导航，视觉风格与项目其他模块不一致。
- 弹窗内仍出现“共享”文案，且存在“组”入口，但当前需求只需支持用户/邮箱，不需要“分享给群组”。
- 无搜索过滤与权限简洁展示，权限添加表单与列表混在一起，易造成操作混乱。

## 排查过程
- 检查 `frontend/src/views/Share.vue` 中的 ACL 对话框，确认存在组类型选项、表格样式老旧、缺少导航与搜索。
- 对照期望样式（左侧导航、右侧用户+权限列表、橙色高亮风格），梳理需要新增的布局与交互元素：导航列、搜索框、权限标签、可读写标签、只读/可读写切换等。

## 修复方案
- 调整 ACL 对话框为左右分栏：左侧静态导航（分享链接/上传链接/分享给用户，当前高亮“分享给用户”），右侧为搜索 + 用户权限列表 + 添加表单。
- 去掉“组”入口，文案全部改为“分享”，权限展示为“可读写/只读/仅预览”标签。
- 增加搜索过滤、只读/可读写单选，统一样式配色与项目主色。

## 实际改动
- `frontend/src/views/Share.vue`：
  - ACL 对话框改为左右分栏布局，新增导航、搜索栏、用户权限卡片式列表、表单区及底部提示。
  - 删除组类型选项，仅保留用户/邮箱；新增“只读/可读写”单选自动映射权限。
  - 文案统一为“分享”，新增权限标签与空态提示，保持按钮与主色一致。
  - CSS 增加导航/列表/表单/底部提示的样式，避免与旧表格风格混用。

## 验证
- 手动检查：打开分享权限弹窗，左侧显示导航（“分享链接”“上传链接”“分享给用户”），右侧可搜索用户并查看“可读写/只读”标签，添加用户时仅支持用户/邮箱，按钮与配色符合现有主题。
- 关闭/保存逻辑不变，保存仍调用原有 `replaceShareAcl` 接口。

## 风险评估
- 改动仅涉及前端分享弹窗 UI 与权限添加映射，未调整接口与数据结构；风险低。
- 若后续需要“分享给群组”，需在表单与导航中重新增加入口，并同步后端解析逻辑。
