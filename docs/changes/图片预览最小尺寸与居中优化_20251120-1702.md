# 图片预览最小尺寸与居中优化（2025-11-20 17:02）

## 一、问题与目标

1. 现状
- 图片预览对话框已经进行了第一轮尺寸优化：
  - 对话框宽度调整为 `70%`；
  - 移除了 body padding；
  - 图片使用 `max-width: 100%`、`max-height: 80vh`、`object-fit: contain` 限制最大尺寸；
  - 图片横向居中展示。
- 在大多数情况下预览效果已经更自然，但对于原始尺寸很小的图片（如小图标、缩略图）：
  - 即便不超过 `max-width` / `max-height`，仍然按原始尺寸显示；
  - 整体看起来“太小”，用户需要凑近才能看清细节。

2. 目标
- 在不改变图片宽高比的前提下，为图片预览设置一个**相对单位的最小尺寸**：
  - 宽度最小约束：`min-width = 80vh`；
  - 高度最小约束：`min-height = 70ch`；
- 当原图小于这个“最小尺寸”时，在不拉伸变形的前提下放大到接近这个最小值；
- 同时保证图片在预览框内居中展示，整体观感更加舒适。

> 注意：`vh`、`ch` 均为相对单位，min-width/min-height 只是“尽量满足”的约束，浏览器会在不破坏宽高比的情况下尽可能放大。

## 二、技术思路

1. 继续依赖浏览器的自适应布局能力
- 对图片设置：
  - `max-width: 100%`：不超出对话框宽度；
  - `max-height: 80vh`：不超出视口高度的 80%；
  - `min-width: 80vh`：期望至少达到“相当于 80% 视口高度”的宽度；
  - `min-height: 70ch`：期望至少达到“约 70 个字符高度”的高度；
- 浏览器的处理逻辑：
  - 若原图较小，min-width/min-height 会驱动元素按比例放大；
  - 若 min-width >= 容器宽度，最终宽度会受 `max-width: 100%` 限制，不会溢出对话框；
  - 由于使用的是 `object-fit: contain`，图片内容会按照宽高比缩放，不会被拉伸或裁切。

2. 居中展示
- 水平居中：
  - 通过 `display: block; margin: 0 auto;` 实现；
- 垂直效果：
  - 对话框 body 去掉 padding，使图片更贴近对话框内容区域；
  - 对于高度较小的图片，min-height 能让图片有一定垂直占比，整体更居中、饱满。

3. 不调整预览逻辑
- 图片预览仍由 `previewImage(file)` 触发：
  - 通过 `/api/files/{id}/preview` 获取 Blob；
  - 使用 `URL.createObjectURL(blob)` 生成 `imagePreviewUrl`；
- 本次仅对样式进行优化，不改动任何请求或逻辑代码。

## 三、具体修改方案

修改文件：`frontend/src/views/files/List.vue`

1. 保持对话框结构不变

当前代码：

```vue
<el-dialog
  v-model="imagePreviewVisible"
  title="图片预览"
  width="70%"
  class="image-preview-dialog"
>
  <img
    v-if="imagePreviewUrl"
    :src="imagePreviewUrl"
    class="image-preview-img"
  />
</el-dialog>
```

不需要调整对话框标签，仅在样式上增强 `image-preview-img`。

2. 在 scoped 样式中为图片增加最小尺寸约束

在现有样式基础上，将 `.image-preview-img` 修改为：

```css
.image-preview-dialog :deep(.el-dialog__body) {
  padding: 0;
}

.image-preview-img {
  max-width: 100%;
  max-height: 80vh;
  min-width: 80vh;
  min-height: 70ch;
  display: block;
  margin: 0 auto;
  object-fit: contain;
}
```

说明：

- `min-width: 80vh`：
  - 希望图片宽度至少约等于视口高度的 80%；
  - 若对话框宽度本身小于 80vh，则最终宽度受 `max-width: 100%` 限制，不会溢出；
  - 对小图而言，会按比例放大，改善“缩在一角”的观感。
- `min-height: 70ch`：
  - 以字符高度为参考，给图片一个相对的最小高度；
  - 结合 `max-height: 80vh` 与 `object-fit: contain`，确保不会拉伸变形。
- 水平居中继续通过 `display: block; margin: 0 auto;` 实现。

## 四、影响评估

1. 正面影响
- 对原始尺寸较小的图片：
  - 预览时会自动放大到约“宽 80vh、高 70ch”的最小视觉尺寸；
  - 用户无需刻意放大即可看清细节；
  - 对话框内图片更加“占据中心”，观感更自然。

- 对原始尺寸较大的图片：
  - 仍受 `max-width: 100%`、`max-height: 80vh` 限制；
  - min-width/min-height 不会起作用，不会影响现有表现。

2. 兼容性与风险
- 修改仅作用于 `image-preview-dialog` 中的图片，对其他页面或对话框无影响；
- 不改变任何 JavaScript 逻辑，风险集中在视觉层；
- 即便浏览器对 `vh`、`ch` 的解释略有差异，也只体现在放大程度的细微不同，不会破坏功能。

## 五、小结

本次优化在“图片预览对话框宽度与布局”已经调整的基础上，进一步为图片设置了**相对单位的最小宽度和高度约束**，并保持居中展示：

- 通过 `min-width: 80vh` + `min-height: 70ch` 在不改变宽高比的前提下放大小图；
- 结合 `max-width: 100%` + `max-height: 80vh`，确保不会溢出预览框；
- 预览体验在小图场景下显著提升，同时保持大图场景下的现有表现。

后续如有需要，可以根据实际使用反馈调整具体数值（如缩放到 70vh/60ch 等），当前实现为一个合理的起点。
