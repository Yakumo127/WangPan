# 文件管理界面样式与操作精简（2025-11-20 22:43）

## 问题成因
- 文件类型展示依赖 content-type，显示冗长 MIME 字符串，用户难以快速识别。
- 文件名样式为蓝色+下划线且无悬停态，操作按钮文字冗长，整体视觉杂乱。
- 操作列图标与文字混排，占用空间且难以聚焦关键操作。
- 缺少固定行高与缩略图，列表视觉密度不均、辨识度低。

## 排查过程与历史
- 复查 `frontend/src/views/files/Explorer.vue` 表格列定义，确认类型列使用 contentType，文件名样式与操作按钮使用文字描述。
- 结合需求，确定需调整类型显示逻辑、文件名与悬停样式、操作区图标化、行高与预览缩略图。

## 修复与优化
- 类型列改为按文件名后缀显示（无后缀显示“文件”，文件夹显示“文件夹”），去除 MIME 字符串。
- 文件名样式改为默认表格色（#303133），移除常态下划线；行 hover 时加下划线。
- 操作列仅保留图标按钮：文件保留下载/重命名/删除图标，其他功能下拉折叠；文件夹保持打开/重命名/删除图标，并配合 Tooltip 提示。
- 表格行高固定 56px，加入缩略图占位：文件显示缩略图（若有），否则展示文件/文件夹图标。
- 新版预览入口仍保留单击预览行为，未删除功能。

## 影响范围
- 前端新文件管理页列表 UI（Explorer），操作交互和样式调整。
- 仅涉及展示与点击事件，未改动数据接口与后端逻辑。

## 验证与建议
- 手动验证：打开新版文件管理页，检查类型列显示简洁后缀；文件名默认无下划线，悬停行加下划线；操作列仅显示图标，点击下载/重命名/删除/下拉预览正常；行高一致；缩略图或图标正常显示。
- 如有自定义字体或主题，需要确保全局样式未覆盖本次局部样式。
