# 分享模块代码改造（2025-11-27 10:54）

## 1. 问题成因
- 分享模块后端缺失实体/接口/权限校验，前端 Share.vue 为占位数据，无法按文档实现“可组合权限 + ACL 覆盖 + 公开/受控分享”。
- 缺少统一的 ACL 判定顺序、公开模式权限限制、提取码防爆破策略的落地代码。

## 2. 排查过程与历史
- 阅读 `docs/specs/分享模块功能拆解与操作日志要求_20251127-1024.md`，明确原子操作、权限位组合、ACL 规则与防爆破要求。
- 确认 SecurityConfig 仅放行 `/api/files/direct-download`、`/api/files/thumbnail/**`，不存在分享公开入口。
- 前端 Share.vue 使用模拟数据，`frontend/src/api` 中无分享相关接口封装。

## 3. 修复建议
- 后端新增 Share/ShareACL 实体与仓库，服务层实现：创建/编辑/撤销、列表、ACL 判定（USER/EMAIL/可选 GROUP）、权限组合校验、提取码哈希与 4 次失败 24 小时封禁、公共访问/下载直链 token 支持 shareId + 权限位组合。
- 控制器拆分：受保护接口 `/api/shares/**`（创建/编辑/撤销/列表/ACL），公开接口 `/api/public/shares/**`（元数据、提取码校验、文件夹子树、下载直链）。
- 安全配置：放行 `/api/public/shares/**`，其余保持鉴权；公开模式仅允许预览/下载，高风险位禁用。
- 前端：新增 `api/share.js`，Share.vue 对接真实接口；公开访问页按权限组合控制按钮显示；错误提示区分“失效/权限不足/提取码错误/封禁”。

## 4. 实际采取的修复操作
- （本次进行中）先行落地后端基础骨架与公开接口放行、数据模型、服务层校验，前端接入真实接口，完成最小可用链路（创建分享、列表、撤销、提取码校验、获取直链并下载）。
