# 存储与空间-总文件占用卡片增加刷新按钮

## 问题与目标
- 现状：系统设置的“存储与空间”页中，总文件占用卡片无直接刷新入口，数据只能依赖页面整体刷新或切换。
- 目标：在总文件占用卡片添加“刷新”按钮，用户可手动触发数据重载。

## 方案摘要
- 前端在“存储与空间”卡片头部新增刷新按钮。
- 按钮触发现有的加载方法，复用原接口逻辑，无需后端改动。

## 实施步骤
1. 在 `System.vue` 的存储与空间卡片标题区域加入刷新按钮。
2. 绑定点击事件调用已有的存储数据加载方法，显示加载状态（与卡片已有 loading 保持一致）。

## 风险与缓解
- 可能短时间重复请求：按需在按钮点击时复用 loading 状态，避免重复点击触发多次请求。

## 影响范围
- 前端仅修改 `frontend/src/views/admin/System.vue`，不涉及后端。
