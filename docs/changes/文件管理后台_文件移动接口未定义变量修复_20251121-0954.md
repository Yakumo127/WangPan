# 文件管理后台移动接口未定义变量修复（2025-11-21 09:54）

## 问题成因
- 后端 `FileController` 的移动接口在构造 `newName` 时引用了不存在的变量 `body`，应使用请求体参数 `request`，导致编译期 “找不到符号 body” 错误，Maven 构建失败。
- 同类接口（复制/重命名等）已使用 `request` 变量，移动接口遗漏了变量名替换。

## 排查过程与历史
- 按编译日志定位 `/backend/src/main/java/com/filemanager/controller/FileController.java` 第 1408 行，发现 `String newName = body.get("newName")...` 变量未定义。
- 搜索其它 `body.get` 使用，确认仅移动接口错用变量名，其余处已正常。

## 修复建议
- 将移动接口中的 `body` 改为当前作用域已有的 `request`，保持与复制接口一致。
- 重新编译验证。

## 实际采取的修复操作
- `backend/src/main/java/com/filemanager/controller/FileController.java`：移动接口中将 `body.get("newName")` 替换为 `request.get("newName")`，确保编译通过。

## 影响评估
- 仅修复编译错误，不改变接口行为；构建可恢复。
