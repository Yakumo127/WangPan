# 文件管理（新版）上传网速展示与分享弹窗改造报告

## 问题成因
- 上传队列仅显示进度百分比，缺少实时上传速率，用户无法判断上传体验与网络状态。
- 文件管理（新版）操作列“分享”按钮当前跳转到“我的分享”页面，无法在当前列表直接操作；现有弹窗样式与流程需替换为新设计。

## 排查过程与历史
- 查阅 `frontend/src/views/files/Explorer.vue`：上传队列 UI 已有进度和状态展示，入口分享按钮通过 `goSharePage` 跳转路由 `Share`。
- 查阅 `frontend/src/composables/useUploadQueue.js`：上传进度更新点在 `directUpload` 的 `onUploadProgress` 和分片上传 `uploadByChunks` 的分片完成逻辑，但未记录速率字段。
- 确认本轮仅前端改动，不对接后端；测试由用户自理。

## 修复建议
- 在上传队列任务结构中新增实时网速字段及时间/字节采样点；在进度回调与分片完成时计算 `deltaBytes / deltaTime`，平滑显示为 KB/s 或 MB/s，并在暂停/完成/失败时归零。
- 在上传队列 UI 追加网速文案，仅在上传中展示，如“上传中 45% · 1.2 MB/s”。
- 移除操作列分享按钮的路由跳转，改为当前页弹出新分享弹窗；弹窗按设计包含左侧菜单（“分享链接/上传链接/分享给用户/分享给群组”）、默认高亮“分享给用户”、右侧用户列表与搜索、提交/关闭按钮，颜色沿用系统主色；采用前端静态数据，占位交互，不调用后端。

## 实际采取的修复操作
- 设计并实现上传速率计算与存储：为任务增加 `speed`、`lastSpeedUploaded`、`lastSpeedTimestamp`，在直传进度与分片完成时更新速率，暂停/失败/完成/取消时清零，确保持久化时保留必要字段。
- 调整上传队列 UI：在进度状态行展示实时网速，完成/暂停等状态不显示速率。
- 移除操作列分享跳转：将文件/文件夹行分享按钮改为打开本页分享弹窗。
- 新增分享弹窗组件：在 `Explorer.vue` 增加新弹窗结构与样式，左侧菜单文案统一使用“分享”，右侧用户列表（含权限标签）、搜索框与提交按钮；使用静态示例数据，暂不对接后端。

## 测试与验证
- 未执行自动化/手动测试（按要求由用户自测）；代码层面检查无明显编译风险，均为前端 Vue/Element Plus 结构与逻辑调整。
