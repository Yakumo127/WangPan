## 1. 项目总体概览

- 技术栈
  - 后端：Spring Boot + Spring Security + JPA（MySQL）+ JWT；异步与定时支持（@EnableAsync, @EnableScheduling）。
  - 前端：Vue 3 + Element Plus，统一通过 `/api` 前缀访问后端（frontend/src/utils/request.js:1）。
  - 日志与监控：Micrometer 指标（audit.metrics.*），审计日志表 user_logs。
- 主要目录
  - 后端代码：`backend/src/main/java/com/filemanager` 下 controller、service、repository、entity、config、security、task、audit 等模块。
  - 配置文件：`backend/src/main/resources/application.yml`（后文引用其关键配置）。
  - 前端 API 壳：`frontend/src/api/*.js`（用于核对接口是否实现）。

## 2. 安全与权限

- 认证方式：JWT。过滤器 `backend/src/main/java/com/filemanager/security/JwtAuthenticationFilter.java:1` 负责从 `Authorization: Bearer <token>` 解析用户名并设置认证上下文。
- 鉴权策略：`backend/src/main/java/com/filemanager/config/SecurityConfig.java:1`
  - 允许匿名：`/api/auth/**`、`/api/files/thumbnail/**`、`/actuator/**`。

  - 入口：`FileController.java:392`

  - 入口：`FileController.java:413`

- DELETE `/files/recycle/bin/empty`（需认证）
  - 入口：`FileController.java:430`
  - 实现：批量“彻底删除”个人回收站内的所有文件（同上逻辑），释放配额并记录审计。

- GET `/files/thumbnail/{fileId}`（公开）
  - 入口：`FileController.java:444`
  - 实现：图片类文件生成/返回缩略图（`FileService.getThumbnailPathPublic` → `ensureThumbnail`）。实现细节包含：
    - 按需子采样 + 双线性缩放；
    - 限制原图体积与像素阈值（application.yml 可配）；
    - 使用 ImageIO 磁盘缓存减轻堆内存压力；
    - 缩略图按用户分目录保存 `${storage}/thumbnails/user_{userId}` 并在记录上缓存路径。

实现要点（FileService）：`backend/src/main/java/com/filemanager/service/FileService.java:1`
- 上传策略（白名单）、空间配额计算、软/硬删除分层（个人回收 → 系统回收 → 到期物理删除）。
- 管理员恢复：物理移动 + 归属切换 + 缩略图清理 + 配额再分配。
- 个人“彻底删除/清空”：仅对本人隐藏，释放配额，不立刻物理删除，便于管理员二次处置与追溯。
- 定时清理：`purgeExpiredScheduledDeletions` 根据到期时间删除物理文件并兜底释放历史配额。

未实现的管理员接口提示（已注释）：原前端 `frontend/src/api/file.js` 存在 `adminEmptyAllRecycleBin()`（DELETE `/files/admin/recycle/bin/empty`），现已注释；后端服务层旧实现 `FileService.adminEmptyAllRecycleBin()` 亦已注释，且控制器未提供对应路由，功能不对外开放。建议改用“单项/批量排期删除”+“到期清理/手动清理到期”。

## 8. 典型数据流与设计取舍

- 删除与回收站分层
  - 用户删除：软删 → 个人回收站（可还原）；
  - 个人“彻底删除/清空”：对本人隐藏并释放配额，不物理删；
  - 管理员视图：系统回收站（仅 ownerHidden 项），支持恢复到管理员网盘或排期删除；
  - 到期删除：定时/手动清理，最终物理删除文件并兜底释放历史配额。

- 上传安全
  - 支持“放开全部”与“白名单后缀”两种策略；
  - 白名单存储在 system_config 中，可热更新且审计记录配置变更。

- 缩略图生成可靠性
  - 大文件/大像素阈值防护；
  - ImageIO 磁盘缓存与子采样控制内存占用；
  - 生成后路径缓存，避免重复生成。
