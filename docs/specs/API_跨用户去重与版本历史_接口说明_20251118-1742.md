# 跨用户去重（CAS）与版本历史 API 说明

本文档描述与 CAS + Versioning 相关的新增/变更接口，包含请求参数与响应示例。

## 1. 全局存在性（跨用户秒传）
- 路由：POST `/api/files/exists-global`
- 请求：`{ "fileHash": "<sha256>" }`
- 响应：
```json
{ "exists": true, "size": 12345, "contentType": "application/pdf" }
```

## 2. 秒传创建（无需上传）
- 路由：POST `/api/files/quick-create`
- 说明：若不传 `parentId` 则创建新文件，传入则在该文件下创建新版本（激活）
- 请求：
```json
{ "fileHash": "<sha256>", "filename": "报告.pdf", "folderId": 1, "parentId": 123 }
```
- 响应：
```json
{ "message": "已创建新版本", "fileId": 123, "filename": "报告.pdf", "size": 12345 }
```

## 3. 上传创建新版本
- 路由A：POST `/api/files/{fileId}/versions/upload`（表单：`file`）
- 路由B：POST `/api/files/upload`（表单：`file`，可选 `parentId`）
- 行为：在 `fileId` 对应文件下创建新版本；配额按“仅计当前版本”口径按差值调整。
- 响应：
```json
{ "message": "已创建新版本", "fileId": 123, "activeVersion": 4, "size": 20480 }
```

## 4. 分片上传创建新版本
- 路由：POST `/api/files/merge`
- 请求体：
```json
{ "fileHash": "<sha256>", "filename": "视频.mp4", "totalChunks": 20, "folderId": 1, "parentId": 123 }
```
- 响应：同上传创建新版本。

## 5. 版本列表
- 路由：GET `/api/files/{fileId}/versions`
- 响应（示例）：
```json
[
  { "id": 11, "versionNo": 1, "blobHash": "aaa...", "size": 100, "contentType": "text/plain", "createdBy": 1, "createTime": "2025-11-18T10:05:00" },
  { "id": 12, "versionNo": 2, "blobHash": "bbb...", "size": 120, "contentType": "text/plain", "createdBy": 1, "createTime": "2025-11-18T10:10:00" }
]
```

## 6. 回档到历史版本
- 路由：POST `/api/files/{fileId}/revert`
- 请求：`{ "versionNo": 2 }`
- 响应：`{ "message": "已回档", "activeVersion": 3 }`
- 说明：回档实现为“追加一个新版本”指向历史 Blob；配额按差值调整。

## 7. 按版本下载
- 路由A：GET `/api/files/download/{fileId}?version={n}`
- 路由B：GET `/api/files/download/{fileId}/version/{versionNo}`
- 说明：ETag 使用 `blob.hash`，支持 Range/If-Range/304。

## 8. 缩略图（公开）
- 路由：GET `/api/files/thumbnail/{fileId}`
- 说明：优先使用 Blob 级缩略图 `{storage}/thumbs/aa/bb/{hash}.jpg`，若源非图片或超阈值则返回 400。

## 9. 管理员运维
- 触发 GC：POST `/api/files/admin/blob/gc` → `{ "removed": 3 }`
- 迁移一批：POST `/api/files/admin/migrate/batch?size=25` → `{ "processed": 25 }`

## 10. 配额口径
- 仅计当前版本：创建新版本时配额增量 = `max(0, new.size - active.size)`；回档同理。

## 11. 错误码与消息
- 常见：400 参数缺失/非法；403 无权限；404 不存在；500 服务器错误。
