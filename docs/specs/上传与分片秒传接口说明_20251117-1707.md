# 上传与分片/秒传接口说明（依据当前实现 2025-11-17）

## 总览
- 支持直传（<=10MB）、分片上传（>10MB）、断点续传（本地 + 服务端分片清单）、同用户秒传。
- 上传白名单策略默认开启（allowAll=false），仅允许配置的后缀（小写、无点、字母数字）。
- 统一异常返回格式；上传超限返回 413。
- 配额扣减为并发安全的原子操作；失败会回滚。
